# Code-Graph – Übersicht

Automatisch erzeugt von `commit-waechter` (nicht von Hand ändern).

Interaktives Netz (Dateien, Funktionen, wer ruft wen): `GRAPH_NETZ.html` im selben Ordner.

**Lesen:** Kasten = Datei, Rahmen = Ordner. Pfeil `A --> B` = Datei A ruft Funktionen
aus B auf (Beschriftung: die häufigsten Funktionen, in Klammern Anzahl Aufrufe).
Gestrichelt = A importiert B, ohne aufgelösten Aufruf. Große Bereiche zeigen zuerst
die Ordner und dann je Ordner, welche Datei wohin zeigt.
